Why does my Supabase project keep pausing?

What causes Supabase free-tier pausing?

Supabase automatically pauses free-tier projects after 7 consecutive days of no database activity. When paused, users cannot sign up, log in, or access any data until the project is manually or automatically unpaused — which can take several minutes and cost you users.

How does SupaWake prevent Supabase from pausing?

SupaWake sends an authenticated request directly to your Supabase REST API every 5 days. This counts as real database activity and resets the 7-day inactivity clock. It runs automatically via GitHub Actions — set it once and forget it.

Is it safe to add my Supabase anon key?

Yes. The anon key is designed to be public — it is embedded in every Supabase frontend app by default. Security is enforced through Row Level Security policies, not by hiding the anon key. Never enter your service_role key into any third-party tool.

Can I keep multiple Supabase projects awake?

Yes. SupaWake supports unlimited projects per account. Add as many as you need — each one is pinged independently on its own schedule.
